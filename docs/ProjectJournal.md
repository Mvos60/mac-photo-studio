# Project Journal

## Decision 001 — No internal database

digiKam owns catalogue functions.

## Decision 002 — Memory cards are never modified automatically

Cards remain untouched until formatted in-camera by the photographer.

## Decision 003 — Filename default: preserve_timestamp

Example:
DSC03452_20260704_195812.ARW

## Decision 004 — digiKam AppImage support

Mac's active digiKam installation is AppImage-based, so Mac Photo Studio must support custom executable paths and AppImage discovery.
